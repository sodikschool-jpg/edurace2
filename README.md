# EDU RACE — Bilim orqali poyga

O‘zbek tilidagi, brauzerda ishlaydigan ikki o‘yinchili bilim poygasi.

## Ishga tushirish
Sayt statik HTML/CSS/JavaScript asosida ishlaydi. `index.html` faylini brauzerda ochish yoki Vercel’da Static Site sifatida deploy qilish kifoya.

## Imkoniyatlar
- Matematika, geometriya va mantiq savollari
- Ikki o‘yinchi navbat bilan o‘ynashi
- Sinf, qiyinlik va poyga uzunligini tanlash
- Brauzer localStorage xotirasida reyting saqlash

Eslatma: reyting faqat joriy brauzerda saqlanadi; global reyting uchun backend va ma’lumotlar bazasi kerak.
